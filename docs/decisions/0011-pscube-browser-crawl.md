# ADR-0011 P's CUBE はぱちタウン経由・画面ありのブラウザで巡回する

## 状況
- 2026-10-23、ユーザーより「株式会社アンジェロから許可を得ている。条件は高頻度アクセスと API 等の非公開経路の利用の禁止。ブラウザ操作で人が確認する程度に」との申告があった。
- 台詳細は P's CUBE を直接開くと error(451) になり、ぱちタウンの店舗ページの iframe 内で人が操作すると表示された。
- ぱちタウン経由でも、画面なしのブラウザ、および画面ありの自動操作（30 秒間隔）では error(451) だった。短時間の繰り返しアクセスによる制限か、自動操作の判定かは未確定。
- 画面表示後の通信（`cgi-bin/nc-m01-001.php` など）を直接呼ぶ方法は、許可条件の「API 等の利用禁止」に当たる。

## 決定
- ぱちタウンの店舗ページを画面ありの Chromium（Playwright）で開き、iframe 内を人の閲覧順にクリックする。画面なしにしない理由は上記の確認結果による（ユーザー判断）。
- 画面遷移の間隔は 30 秒以上、同時に開くのは 1 ページ、1 日 1 回（23:30）。robots.txt を確認する。
- UA の偽装、webdriver の隠蔽、操作の揺らぎの模倣など、検知を回避する処理は入れない。error(451) が出たら、その回の台詳細巡回を打ち切り、再試行しない。
- 非公開のデータ取得 URL を直接呼ばない。画面の HTML を原本として保存して解析する。
- 機種画面（日別 BONUS 回数）は取得元 `pscube_list`（優先度 15）、台詳細は `pscube`（優先度 10）として記録し、台詳細を優先する。
- 収集は別の Windows PC でタスクスケジューラから実行する。画面ありのため、ユーザーがログオンしている間のみ実行する（`docs/deploy_windows.md`）。

## 影響
- 1 回の収集に約 1 時間かかる（約 120 画面 × 30 秒）。
- 台詳細の拒否が続く場合は、運営者に相談する。拒否を回避する方向の変更はしない。
