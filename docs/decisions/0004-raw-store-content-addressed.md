# ADR-0004 原本ストアは内容アドレス方式・gzip・不変

## 決定
- パスは `rawstore://sha256/ab/cd/<sha256>.gz`。SHA-256 は圧縮前のバイト列から計算する。
- 書き込みは一時ファイル → 展開して検証 → rename で行う。既存ファイルは上書きせず、ハッシュを検証してから再利用する。破損していれば例外にし、正規化に進まない。書き込み後は読み取り専用にする。
- DB には URI・SHA-256・サイズ・メディア型を記録する。取得イベントは毎回記録し、同一内容のファイルは 1 つにまとめる。
- ストアのルートは設定で決める。S3 互換などは `RawStore` プロトコルを実装して差し替える。

## 影響
バックアップは差分コピーで済む（ファイル名がハッシュなので変更が無い）。
