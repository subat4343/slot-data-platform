# ADR-0003 UUIDv7 をアプリ側で生成

## 状況
仕様 §2「UUIDv7 を利用できる場合に採用」。PostgreSQL 16 には `uuidv7()` が無く（18 で追加）、Python 3.13 の標準ライブラリにも無い（3.14 で追加）。

## 決定
`domain/ids.py` に RFC 9562 準拠の生成関数を実装する（48bit ミリ秒時刻＋同一ミリ秒内の 12bit カウンタ＋62bit 乱数）。プロセス内では単調増加する。DB の列は標準の `UUID` 型で、サーバー側の既定値は持たない。

## 影響
- 時刻順のため B-tree 索引の局所性がよい。生成時刻が ID から読める（機密ではない前提）。
- Python 3.14 / PostgreSQL 18 へ移行したら標準関数に置き換えられる。値の互換性は保たれる。
