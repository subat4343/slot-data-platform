# ADR-0012 P's CUBE 巡回で自動操作の目印を無効化する

ADR-0011 の「検知を回避する処理は入れない」を、この ADR で置き換える。

## 状況
- 台詳細のデータ通信（`nc-m06-001.php`）は、ページ内スクリプトが生成するトークン付きで送られ、自動操作のブラウザでは HTTP 451 で拒否された（2026-10-25）。
- 2026-10-26、ユーザーより運営側の線引きの補足があった:「通常のブラウザで取得できる範囲で、人が毎晩確認してノートに記録する程度の定点収集は可。毎秒アクセスなど人には不可能な頻度・データ差分の取得は不可。自動操作そのものは否定していない」。
- ユーザーが `browser.py` に、自動操作の目印を無効化する設定（`--disable-blink-features=AutomationControlled`、`navigator.webdriver` を undefined にする初期化スクリプト）を追加した（コミット 46cb96a）。この設定で、台詳細が表示されることを確認した（2026-10-26 05:34）。

## 決定
- 上記 2 つの設定を採用し、台詳細を巡回する（`crawl_details: true`）。
- 頻度は 1 日 1 回（23:30）、画面遷移 30 秒間隔、同時 1 ページ、robots.txt 遵守を維持する。
- これ以上の回避策は入れない。具体的には、CAPTCHA の突破、トークン生成スクリプトの解析・再現、非公開のデータ取得 URL の直接呼び出し、人の操作の揺らぎの模倣、頻度の引き上げ、IP の分散。
- error(451)・CAPTCHA のチャレンジ・403・429 が出たら、その回の台詳細巡回を打ち切り、欠損理由を記録する。続く場合は運営側に相談する。

## 根拠と留意点
- 許可と線引きの根拠はユーザー申告であり、書面の所在は `config/sources/pscube.yaml` の `permission_reference` に追記すること。
- サイト側の技術的な拒否は、運営会社とは別の事業者（ページの著作権表示はアクティブネットジャパン）による可能性がある。運営側の見解が変わった場合や、拒否が強化された場合は、この ADR を見直す。
