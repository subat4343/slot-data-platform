# ADR-0009 配置の位置関係・角台の算出規則

## 決定（仮定を含む）
- `sequence_no` は、同じ島の両側で共通の物理的基準端から数えた台枠番号とする（仕様 §7）。
- 位置種別: `machine`（台）、`empty`（台の無い台枠。列は途切れない）、`aisle`（通路）、`pillar`（柱）。通路と柱は列を分断する。
- 隣（next_to）: 同じ島・同じ側で、sequence_no が 1 違いの machine どうし。欠番（番号の飛び）は位置不明として隣接を作らず、検証で `SEQUENCE_GAP` 警告を出す。連番だけで隣接を推測しない。
- 背中合わせ（back_to_back）: 側がちょうど 2 つの島で、同じ sequence_no の machine どうし。側が 3 つ以上の島では作らない（警告）。
- 対面（across_aisle）: CSV の情報だけでは一意に決まらないため、自動生成しない。draft 版に人が登録する。
- 角: 分断されない区間の端からの台枠数（1 = 角、2 = 角2）。空き台枠も台枠として数える。端の台枠が空きなら、その隣の台は角2。**この解釈は店舗運用での「角」の定義と合うか確認が必要。**
- 位置関係は無向とし、`position_a_id < position_b_id` に正規化する。矛盾（同じ組に複数種別、別の島どうしの next_to など）は公開時に検査して拒否する。
- 公開済み版は不変とする。後続版の公開時に、前版の `valid_to` を NULL から日付へ 1 回だけ確定できる。新版の `valid_from` は最新公開版より後でなければならない（過去への差し込みは未対応）。
- 現行版と同一内容の CSV からは新版を作らない（`NO_CHANGES`）。
